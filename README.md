# Проект с историями

## Описание
Веб-проект с романтическими историями. Содержит 5 историй по 50 сцен каждая.

## Структура проекта
```
story-project/
├── server.js           # Node.js сервер с автопингом
├── package.json        # Зависимости
└── public/             # Статические файлы
    ├── index.html      # Главное меню
    ├── css/           
    │   └── style.css   # Стили
    ├── story1/         # История "Мы выросли рядом" (50 сцен)
    ├── story2/         # История "Папина дочка" (в разработке)
    ├── story3/         # История "После звонка" (в разработке)
    ├── story4/         # История "Второй шанс" (в разработке)
    └── story5/         # История "Стрим и реальность" (в разработке)
```

## Установка и запуск локально

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер: http://localhost:3000

## Деплой на Render

1. Зарегистрируйтесь на https://render.com

2. Создайте новый Web Service:
   - Connect your repository (загрузите код на GitHub)
   - Или используйте "Deploy from GitHub"

3. Настройки:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Environment: Node

4. Сервер автоматически пингует себя каждые 10 минут, чтобы не засыпать на бесплатном тарифе.

## Особенности

- Адаптивный дизайн для мобильных устройств
- Красивый интерфейс
- Пагинация по страницам
- Автоматический пинг сервера (анти-сон для Render)
- Простой и читаемый текст

Полноценная история на 50 сцен о двух людях, которые выросли вместе и полюбили друг друга. История написана максимально человечески, с эмоциями и деталями.
